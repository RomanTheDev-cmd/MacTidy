# Icon assets

`MacSpace-icon.svg` is the editable vector source for the current icon: the blue brush and sparkle on a dark graphite tile with a light outline, so it stays visible on light and dark backgrounds. `MacSpace-icon.png` is its 1024-pixel render, and `MacSpace.icns` packages the 16–1024 pixel macOS icon sizes. The earlier MacTidy assets remain for reference.
