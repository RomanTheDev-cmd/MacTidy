# MacSpace 2.8.2

Нативное приложение на SwiftUI для анализа места и переноса выбранных объектов в Корзину. Готовая сборка — Apple Silicon, macOS 13+. Интерфейс использует системный Liquid Glass на macOS 26 и новее (проверено на macOS 27), на более старых версиях — стандартные полупрозрачные материалы. Светлая/тёмная тема следует настройке системы. Графитовые кнопки имеют контрастные подписи.

## Установка

1. Скачайте **MacSpace-2.8.2-arm64.pkg** из [последнего релиза](https://github.com/RomanTheDev-cmd/MacTidy/releases/latest).
2. Откройте файл и пройдите обычные шаги установщика macOS.
3. Запустите MacSpace из папки «Программы».

Установщик самостоятельный, инструменты разработчика не нужны. Требуются Apple Silicon (M1 и новее) и macOS 13+. Перед обновлением закройте приложение. Установка не запускает очистку и не включает расписание; существующие настройки сохраняются. Установщик заменяет прежнее приложение MacTidy и сохраняет скрытую ссылку для старого значка в Dock.

При первом запуске появляется один экран настройки доступа к файлам со ссылкой на «Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску». Установщик и приложение не могут предоставить это разрешение сами: подтверждение требует macOS. Можно продолжить без полного доступа, но часть папок в обзоре диска будет недоступна. После изменения доступа перезапустите MacSpace. Экран можно повторно открыть из настроек анализа; они закрываются крестиком или Escape.

Для еженедельной очистки «Загрузок» доступ нужен и отдельному приложению **MacSpace Helper**. При включённом расписании на экране доступа есть кнопка «Показать помощник»: добавьте его в тот же список полного доступа к диску. Без доступа помощник сообщит об ошибке и сохранит файлы.

Сборка имеет ad-hoc подпись, установщик не подписан сертификатом Developer ID и не нотарифицирован Apple. Если macOS блокирует скачанный файл, после попытки открытия найдите «Всё равно открыть» в «Системные настройки → Конфиденциальность и безопасность», если доверяете этой сборке. На управляемом Mac эта возможность может быть запрещена.

## Языки

Язык выбирается по первому предпочитаемому языку системы или приложения. В комплекте: русский, английский, немецкий, испанский, итальянский, вьетнамский, польский и индонезийский. Для остальных языков, поддерживаемых Apple Translation, на macOS 15+ используется системный переводчик с возможным запросом загрузки языковой модели. При отказе, ошибке или неподдерживаемом языке остаётся английский интерфейс. Изменение языка применяется после перезапуска. Дополнительные переводы машинные; исправления приветствуются.

Переводятся только фиксированные подписи интерфейса. Имена, пути и содержимое ваших файлов не передаются переводчику. Для арабского и иврита предусмотрено направление справа налево. Поддержка буквально всех языков не заявляется.

## Обновления

При открытии главного окна MacSpace проверяет последний релиз на GitHub. Если версия новее, приложение загружает пакет, проверяет SHA-256 и подпись Ed25519, затем один раз открывает стандартный установщик macOS. Для завершения установки следуйте его шагам; система может запросить пароль администратора. Приложение не может обойти подтверждение macOS. Если вы отложили установку, откройте «Настройки → Проверить обновления → Открыть установщик».

Проверка связывается только с GitHub и не передаёт имена или содержимое найденных файлов. Автоматический установщик принимает только релизы с подписанным `.pkg`; неподписанные локальные сборки можно установить вручную. Для подписи официального релиза `package.command` читает путь к закрытому ключу из `MACTIDY_SIGNING_KEY`. Закрытый ключ хранится вне репозитория.

## Главное окно

На первом экране одна основная кнопка «Анализировать». После анализа появляется список: выберите ненужные файлы и подтвердите перенос в Корзину. Категории, порог размера и еженедельное расписание находятся в настройках. Поиск, сортировка, фильтр категорий, множественный выбор, переход в Finder и исключение объектов доступны при просмотре результатов.

Ничего не выбирается автоматически. Файлы, подходящие под несколько категорий, учитываются один раз. При наличии папки кэша её вложенные файлы не дублируются отдельными строками. Выбор сохраняется при смене фильтра, а скрытые выбранные объекты явно учитываются в нижней панели и подтверждении.

| Категория | Область и правило |
| --- | --- |
| Кэш приложений | Непосредственные объекты ~/Library/Caches с проверкой вложенного содержимого |
| Старые журналы | Обычные файлы ~/Library/Logs, изменённые более 30 дней назад |
| Установщики | DMG, PKG, MPKG, ISO, XIP в ~/Downloads и вложенных папках; только обычные файлы |
| Архивы | ZIP, RAR, 7Z, TAR, GZ, BZ2, XZ, TGZ, ZST в ~/Downloads |
| Старые загрузки | Обычные файлы, созданные, добавленные и изменённые более 30 дней назад; отсутствие даты создания не считается старостью |
| Сборки Xcode | Только ~/Library/Developer/Xcode/DerivedData; по умолчанию выключено |
| Большие файлы | Выбранная папка, порог 50/100/500 МБ или 1 ГБ |

Перед очисткой кэша закройте соответствующие приложения; перед очисткой DerivedData закройте Xcode. Следующий запуск или сборка могут занять больше времени. Кэш может содержать офлайн-данные для повторной загрузки. Возраст и размер файла не означают, что он больше не нужен.

Скрытые объекты, символические ссылки, пакеты приложений и вложенные Library, System, Applications, node_modules, .git не обходятся при рекурсивном поиске обычных файлов. Кэш измеряется отдельно, включая скрытое содержимое. Недоступные папки кэша не предлагаются для переноса. Технические пропуски анализа не отображаются; ошибка чтения выбранной папки показывается отдельно. Отсутствующие необязательные папки могут давать пустую категорию.

Исключения сохраняются между запусками. Если исключённый файл находится внутри папки кэша, исключается вся эта папка, чтобы не переместить его косвенно. Кнопка «Вернуть исключённые» очищает список исключений; затем нужен новый анализ.

Размер обычных файлов — логический, папок кэша и приложений — сумма выделенных блоков. Облачные файлы, сжатие, общие блоки APFS и снимки влияют на фактическое освобождение места. Перед переносом повторно проверяются путь, идентичность, размер, даты изменения и состав вложенных папок. Эта проверка не является атомарной защитой от одновременного изменения файлов.

## Отдельное окно «Приложения»

В обзоре «Память по типам» приложения учитываются отдельной категорией. После анализа там показываются до трёх программ, которые, согласно Spotlight, не открывались 90 дней. Это подсказки: ничего не выбирается автоматически. Кнопка проверки открывает окно ниже с полным списком и фильтрами.

Открывается через меню «Ещё» в верхней части главного окна. Сначала показывает одну кнопку проверки, затем — список приложений. Проверяет /Applications и ~/Applications, включая вложенные папки, но не внутреннее содержимое приложений как отдельные приложения. /System/Applications, ссылки на приложения и сам MacSpace не предлагаются к удалению.

Фильтры: не открывались 30, 90 или 180 дней, либо все приложения. Дата последнего запуска берётся из Spotlight. Отсутствующая или неполная история не означает, что программа редко используется: такие приложения показываются только при включении «Показать без истории» или выборе всех приложений.

Запущенные приложения нельзя выбрать для удаления. Приложения, для которых не хватает прав на запись в пакет или родительскую папку, помечаются заранее и не попадают в «Выбрать все»; при необходимости их можно найти в Finder. Список запущенных обновляется по системным событиям и повторно проверяется перед переносом. Изменённое после анализа приложение не переносится до повторной проверки.

Переносится только пакет .app. Документы, настройки, Application Support и другие пользовательские данные не удаляются. Некоторые программы со службами, расширениями или драйверами требуют фирменного деинсталлятора. Приложения, защищённые macOS или правами доступа, могут не перенестись; ошибка будет показана. Программа не повышает права администратора.

## Память по типам

Кнопка «Память по типам» в главном окне открывает обзор личных файлов: фото, видео, аудио, документы, установщики, архивы, приложения и другие файлы. Установочные пакеты DMG, PKG, MPKG, ISO и XIP находятся в категории «Установщики». В каждой категории личных файлов, включая «Другие файлы», можно выбрать отдельные объекты или все видимые объекты и подтвердить перенос в Корзину. Смена категории сбрасывает выбор. Приложения проверяются в отдельном окне с защитой запущенных программ.

Обзор ищет файлы только в стандартных личных папках: Рабочий стол, Документы, Загрузки, Фильмы, Музыка и Изображения. Скрытые объекты, ссылки, вложенные пакеты и защищённые каталоги пропускаются. Файлы неизвестных типов из личных папок можно просмотреть и выбрать для очистки; система, недоступные и неразобранные данные в этот список не попадают. Показанные размеры могут отличаться от данных macOS из-за снимков APFS, общих блоков и облачных файлов.

Показатель «Доступно» учитывает место, которое macOS может освободить автоматически, как в Системных настройках. Физически свободного места может быть меньше из-за локальных снимков и других освобождаемых данных. Оценка размера выбранных файлов не гарантирует такой же немедленный прирост свободного места.

Кнопка «Что можно освободить» показывает конкретные крупные личные файлы, пользовательские папки данных программ и отдельные удаляемые материалы сторонних программ, например библиотеки в `/Library/Arturia`. У каждой строки есть действия просмотра в Finder и переноса в Корзину. Перед переносом появляется подтверждение, а путь, идентичность и доступность повторно проверяются. Общая папка «Пользователи», системные каталоги и защищённые данные Apple в список очистки не попадают. Удаление библиотеки или пресетов может нарушить работу программы; сначала закройте её и проверьте содержимое. Размеры приблизительны из-за снимков APFS, общих блоков и ограничений доступа.

Пункт «Локальные копии iCloud» в меню «Ещё» окна памяти показывает только файлы, которые уже полностью загружены в облако и имеют копию на Mac. Кнопка «Удалить загрузку» после подтверждения убирает только локальную копию через системный механизм macOS; файл остаётся в iCloud. При открытии он может загрузиться снова. Обычная очистка и еженедельное задание пропускают объекты iCloud.

Пункт «Освободить место…» в меню «Ещё» окна памяти принимает желаемый объём в ГБ и показывает варианты: установщики и архивы, старые загрузки, крупные личные файлы и смешанный подбор. Редко используемые приложения можно открыть для отдельной проверки. Каждый вариант содержит конкретный список и оценку места; если подходящих файлов недостаточно, это показано явно. Перед переносом в Корзину можно снять любую галочку и подтвердить итоговый выбор. Приложение ничего не удаляет при вводе цели.

## Еженедельная очистка Загрузок

Переключатель «Автоочистка загрузок» находится в настройках анализа. При первом включении требуется подтверждение: каждое воскресенье в 12:00 по времени Mac **всё содержимое ~/Downloads**, включая новые файлы, скрытые объекты и целые папки, переносится в Корзину. Символические ссылки переносятся как ссылки, их цели не обходятся. Корзина не очищается. Эта опция не зависит от галочек категорий ручного анализа.

Расписание работает через пользовательский LaunchAgent, после входа пользователя, даже при закрытом MacSpace. Пропущенный во время сна запуск может произойти при пробуждении. На выключенном Mac и до входа пользователя задача не работает. Включение не запускает немедленную очистку. Ранее включённое расписание сохраняется при обновлении приложения.

Помощник установлен в ~/Library/Application Support/MacTidy/MacTidyHelper.app. Расписание: ~/Library/LaunchAgents/local.mactidy.weekly-downloads.plist. Результат: ~/Library/Application Support/MacTidy/weekly-report.json. Выключение переключателя останавливает задание и удаляет plist. Перед удалением MacSpace отключите эту опцию.

Если macOS запрещает помощнику доступ к Загрузкам, файлы сохраняются и ошибка отражается в результате запуска. Результат обновляется при возвращении в MacSpace. Неудачные объекты не блокируют остальные; немедленных повторов нет.

## Сборка и проверка

`build.command` собирает приложение под архитектуру текущего Mac; нужны Apple Command Line Tools с SwiftUI и SDK macOS 26+ для сборки стеклянного интерфейса. Сборка имеет локальную ad-hoc подпись, не нотарифицирована Apple для публичного распространения. Сине-серебристая иконка сделана как векторный SVG; PNG с прозрачным фоном и готовый ICNS находятся в Assets.

`test.command` запускает проверки обхода и исключений, отмены, устаревших метаданных, ссылок, типов файлов и установщиков, изменений вложенного кэша, фильтров дат, устранения повторов, защиты исключённых файлов, редко используемых приложений и недельного расписания. Реальный перенос в Корзину и восстановление проверяются только на специально созданном временном файле. Перенос пользовательских файлов и приложений при разработке не выполнялся.

Приложение работает локально и не отправляет найденные имена и содержимое файлов в сеть.

Для сборки самостоятельного установщика запустите `./package.command`: результат появится в `dist/` вместе с SHA-256. Исходники: [GitHub](https://github.com/RomanTheDev-cmd/MacTidy), лицензия [MIT](LICENSE). При обновлении основной программы включённый помощник сохраняется; чтобы обновить его, выключите и снова включите расписание.
