# MacSpace 3.0.4

Нативное приложение на SwiftUI для анализа места и переноса выбранных объектов в Корзину. Готовая сборка — Apple Silicon, macOS 13+. Интерфейс использует системный Liquid Glass на macOS 26 и новее (проверено на macOS 27), на более старых версиях — стандартные полупрозрачные материалы. Светлая/тёмная тема следует настройке системы. Графитовые кнопки имеют контрастные подписи.

## Установка

1. Скачайте **MacSpace-3.0.4-arm64.pkg** из [последнего релиза](https://github.com/RomanTheDev-cmd/MacTidy/releases/latest).
2. Откройте файл и пройдите обычные шаги установщика macOS.
3. Запустите MacSpace из папки «Программы».

Установщик самостоятельный, инструменты разработчика не нужны. Требуются Apple Silicon (M1 и новее) и macOS 13+. Перед обновлением закройте приложение. Установка не запускает очистку и не включает расписание; существующие настройки сохраняются. Установщик заменяет прежнее приложение MacTidy и сохраняет скрытую ссылку для старого значка в Dock.

MacSpace запускается без мастера настройки и проверяет доступные ему файлы. Для защищённых папок в настройках анализа есть ссылка на «Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску». Установщик и приложение не могут предоставить это разрешение сами: подтверждение требует macOS. После изменения доступа перезапустите MacSpace. Экран настроек закрывается крестиком или Escape.

Для автоочистки «Загрузок» доступ нужен и отдельному приложению **MacSpace Helper**. При включённом расписании на экране доступа есть кнопка «Показать помощник»: добавьте его в тот же список полного доступа к диску. Без доступа помощник сообщит об ошибке и сохранит файлы.

### Если macOS пишет, что файл «не был открыт»

При первом запуске macOS может показать: *«Файл "MacSpace-…-arm64.pkg" не был открыт. Apple не удалось подтвердить, что он не содержит вредоносного ПО».* Это ожидаемо и не значит, что файл опасен. **Не нажимайте «Переместить в Корзину».**

1. Нажмите **«Готово»**.
2. Откройте **«Системные настройки → Конфиденциальность и безопасность»**.
3. Пролистайте вниз до раздела **«Безопасность»**. Рядом с сообщением о «MacSpace-…-arm64.pkg» нажмите **«Всё равно открыть»**.
4. Подтвердите паролем или Touch ID и ещё раз нажмите **«Открыть»**. Запустится установка.

При открытии установщика следующего обновления macOS может снова запросить разрешение.

**Почему так происходит.** Apple показывает это предупреждение для каждой программы, которая не прошла нотаризацию — проверку и заверение у Apple с платным сертификатом разработчика (99 $ в год). MacSpace — бесплатный независимый проект и пока не использует этот платный сертификат. Вместо этого каждый выпуск подписан собственным ключом проекта, и программа проверяет эту подпись перед установкой обновления, поэтому подменить обновление нельзя. На Mac, которыми управляет организация, администратор может запретить кнопку «Всё равно открыть».

В главном окне есть вкладка «Антивирус» со встроенным движком ClamAV. MacSpace проверяет официальные базы при запуске и каждые два часа, пока приложение открыто. Если обновление не удалось, приложение само повторит попытку через 3, 10, 30 и 60 секунд, затем каждые пять минут; уже загруженная база остаётся доступной. Первая загрузка требует интернета; базы хранятся отдельно в Application Support, а дальнейшие обновления FreshClam по возможности загружает небольшими изменениями. Полная проверка запускается только после нажатия кнопки «Искать вирусы». Сначала программа считает доступные файлы, затем показывает число проверенных файлов, прошедшее и примерное оставшееся время и находки сразу после обнаружения. Долгую проверку можно остановить. Последние 20 проверок и находки сохраняются локально в истории. Для доступа к защищённым пользовательским папкам нужен «Полный доступ к диску». iCloud исключён из проверки. Найденные файлы останутся нетронутыми, пока вы не выберете «Переместить в Корзину» и не подтвердите действие. MacSpace не очищает Корзину и не отправляет файлы в сеть.

В приложение включён официальный универсальный движок macOS [ClamAV](https://github.com/Cisco-Talos/clamav) 1.5.4 под лицензией GPL-2.0-or-later. Сборка проверяет закреплённую SHA-256 сумму официального пакета перед встраиванием. Базы вирусов хранятся в Application Support пользователя. `package.command` также создаёт архив исходного кода ClamAV; опубликуйте его в том же релизе, что и установщик MacSpace. Исходный код и лицензия доступны в [официальном релизе ClamAV 1.5.4](https://github.com/Cisco-Talos/clamav/releases/tag/clamav-1.5.4). Сканируемые файлы и пути остаются на Mac.

## Языки

Язык выбирается по первому предпочитаемому языку системы или приложения. В комплекте: русский, английский, немецкий, испанский, итальянский, вьетнамский, польский и индонезийский. Для остальных языков, поддерживаемых Apple Translation, на macOS 15+ используется системный переводчик с возможным запросом загрузки языковой модели. При отказе, ошибке или неподдерживаемом языке остаётся английский интерфейс. Изменение языка применяется после перезапуска. Дополнительные переводы машинные; исправления приветствуются.

Переводятся только фиксированные подписи интерфейса. Имена, пути и содержимое ваших файлов не передаются переводчику. Для арабского и иврита предусмотрено направление справа налево. Поддержка буквально всех языков не заявляется.

## Обновления

При каждом запуске MacSpace проверяет обновления только в репозитории **RomanTheDev-cmd/MacTidy**. Если есть более новая подписанная сборка для Apple Silicon, появляется окно с кнопками «Обновить сейчас» и «Позже». Пакет загружается и стандартный установщик macOS открывается только после выбора «Обновить сейчас». Перед этим проверяются SHA-256 и подпись Ed25519. Для завершения следуйте шагам установщика; система может запросить пароль администратора. После выбора «Позже» предложение появится при следующем запуске. В любой момент обновление можно начать через «Настройки анализа → Проверить обновления → Обновить сейчас».

Проверка обновлений приложения связывается только с GitHub и не передаёт имена или содержимое найденных файлов. Автоматический установщик принимает только релизы с подписанным `.pkg`; неподписанные локальные сборки можно установить вручную. Для подписи официального релиза `package.command` читает путь к закрытому ключу из `MACTIDY_SIGNING_KEY`. Закрытый ключ хранится вне репозитория.

## Главное окно

На первом экране одна основная кнопка «Анализировать». После анализа появляется список: выберите ненужные файлы и подтвердите перенос в Корзину. Категории, порог размера и расписание автоочистки находятся в настройках. Поиск, сортировка, фильтр категорий, множественный выбор, переход в Finder и исключение объектов доступны при просмотре результатов.

Ничего не выбирается автоматически. Файлы, подходящие под несколько категорий, учитываются один раз. При наличии папки кэша её вложенные файлы не дублируются отдельными строками. Выбор сохраняется при смене фильтра, а скрытые выбранные объекты явно учитываются в нижней панели и подтверждении.

| Категория | Область и правило |
| --- | --- |
| Кэш приложений | Непосредственные объекты ~/Library/Caches с проверкой вложенного содержимого |
| Старые журналы | Обычные файлы ~/Library/Logs, изменённые более 30 дней назад |
| Установщики | DMG, PKG, MPKG, ISO, XIP в ~/Downloads и вложенных папках; только обычные файлы |
| Архивы | ZIP, RAR, 7Z, TAR, GZ, BZ2, XZ, TGZ, ZST в ~/Downloads |
| Старые загрузки | Обычные файлы, созданные, добавленные и изменённые более 30 дней назад; отсутствие даты создания не считается старостью |
| Сборки Xcode | Только ~/Library/Developer/Xcode/DerivedData; по умолчанию выключено |
| Большие файлы | Выбранная папка, порог 50/100/500 МБ или 1 ГБ |

Перед очисткой кэша закройте соответствующие приложения; перед очисткой DerivedData закройте Xcode. Следующий запуск или сборка могут занять больше времени. Кэш может содержать офлайн-данные для повторной загрузки. Возраст и размер файла не означают, что он больше не нужен.

Скрытые объекты, символические ссылки, пакеты приложений и вложенные Library, System, Applications, node_modules, .git не обходятся при рекурсивном поиске обычных файлов. Кэш измеряется отдельно, включая скрытое содержимое. Недоступные папки кэша не предлагаются для переноса. Технические пропуски анализа не отображаются; ошибка чтения выбранной папки показывается отдельно. Отсутствующие необязательные папки могут давать пустую категорию.

Исключения сохраняются между запусками. Если исключённый файл находится внутри папки кэша, исключается вся эта папка, чтобы не переместить его косвенно. Кнопка «Вернуть исключённые» очищает список исключений; затем нужен новый анализ.

Размер обычных файлов — логический, папок кэша и приложений — сумма выделенных блоков. Облачные файлы, сжатие, общие блоки APFS и снимки влияют на фактическое освобождение места. Перед переносом повторно проверяются путь, идентичность, размер, даты изменения и состав вложенных папок. Эта проверка не является атомарной защитой от одновременного изменения файлов.

## Вкладка «Приложения»

В обзоре «Память по типам» приложения учитываются отдельной категорией. После анализа там показываются до трёх программ, которые, согласно Spotlight, не открывались 90 дней. Это подсказки: ничего не выбирается автоматически. Кнопка проверки открывает вкладку «Приложения» главного окна с полным списком и фильтрами.

Вкладка в главном окне рядом с «Очисткой» и «Антивирусом». Сначала показывает одну кнопку проверки, затем — список приложений. Проверяет /Applications и ~/Applications, включая вложенные папки, но не внутреннее содержимое приложений как отдельные приложения. /System/Applications, ссылки на приложения и сам MacSpace не предлагаются к удалению.

Фильтры: не открывались 30, 90 или 180 дней, либо все приложения. Дата последнего запуска берётся из Spotlight. Отсутствующая или неполная история не означает, что программа редко используется: такие приложения показываются только при включении «Показать без истории» или выборе всех приложений.

Запущенные приложения нельзя выбрать для удаления. Приложения в папках с ограниченными правами остаются доступными для выбора, но macOS запросит подтверждение администратора при переносе в Корзину. Для группы выбранных приложений запрос выполняется один раз. Список запущенных обновляется по системным событиям и повторно проверяется перед переносом. Изменённое после анализа приложение не переносится до повторной проверки.

Переносится только пакет .app. Документы, настройки, Application Support и другие пользовательские данные не удаляются. Некоторые программы со службами, расширениями или драйверами требуют фирменного деинсталлятора. Если macOS не разрешит перенос, приложение останется на месте.

## Память по типам

Кнопка «Память по типам» в главном окне открывает обзор личных файлов: фото, видео, аудио, документы, установщики, архивы, приложения и другие файлы. Установочные пакеты DMG, PKG, MPKG, ISO и XIP находятся в категории «Установщики». В каждой категории личных файлов, включая «Другие файлы», можно выбрать отдельные объекты или все видимые объекты и подтвердить перенос в Корзину. Смена категории сбрасывает выбор. Приложения проверяются на вкладке «Приложения» с защитой запущенных программ.

Обзор ищет файлы только в стандартных личных папках: Рабочий стол, Документы, Загрузки, Фильмы, Музыка и Изображения. Скрытые объекты, ссылки, вложенные пакеты и защищённые каталоги пропускаются. Файлы неизвестных типов из личных папок можно просмотреть и выбрать для очистки; система, недоступные и неразобранные данные в этот список не попадают. Показанные размеры могут отличаться от данных macOS из-за снимков APFS, общих блоков и облачных файлов.

Показатель «Доступно» учитывает место, которое macOS может освободить автоматически, как в Системных настройках. Физически свободного места может быть меньше из-за локальных снимков и других освобождаемых данных. Оценка размера выбранных файлов не гарантирует такой же немедленный прирост свободного места.

Кнопка «Что можно освободить» показывает конкретные крупные личные файлы, пользовательские папки данных программ и отдельные удаляемые материалы сторонних программ, например библиотеки в `/Library/Arturia`. У каждой строки есть действия просмотра в Finder и переноса в Корзину. Перед переносом появляется подтверждение, а путь, идентичность и доступность повторно проверяются. Общая папка «Пользователи», системные каталоги и защищённые данные Apple в список очистки не попадают. Удаление библиотеки или пресетов может нарушить работу программы; сначала закройте её и проверьте содержимое. Размеры приблизительны из-за снимков APFS, общих блоков и ограничений доступа.

Пункт «Локальные копии iCloud» в меню «Ещё» окна памяти показывает только файлы, которые уже полностью загружены в облако и имеют копию на Mac. Кнопка «Удалить загрузку» после подтверждения убирает только локальную копию через системный механизм macOS; файл остаётся в iCloud. При открытии он может загрузиться снова. Обычная очистка и автоочистка пропускают объекты iCloud.

Пункт «Освободить место…» в меню «Ещё» окна памяти принимает желаемый объём в ГБ и показывает варианты: установщики и архивы, старые загрузки, крупные личные файлы и смешанный подбор. Редко используемые приложения можно открыть для отдельной проверки. Каждый вариант содержит конкретный список и оценку места; если подходящих файлов недостаточно, это показано явно. Перед переносом в Корзину можно снять любую галочку и подтвердить итоговый выбор. Приложение ничего не удаляет при вводе цели.

## Автоочистка Загрузок

Переключатель «Автоочистка загрузок» и выбор периодичности находятся в настройках анализа. Можно выбрать каждый день, раз в неделю или раз в месяц. В 12:00 по времени Mac **всё содержимое ~/Downloads**, включая скрытые объекты и целые папки, переносится в Корзину. Служебные файлы Finder `.localized` и `.DS_Store` остаются, поэтому папка сохраняет название «Загрузки». Недокачанные файлы (`.crdownload`, `.download`, `.part`, `.partial`, `.opdownload`) и объекты, изменённые за последние 10 минут, остаются до следующего запуска. Символические ссылки переносятся как ссылки, их цели не обходятся. Корзина никогда не очищается автоматически. Эта опция не зависит от галочек категорий ручного анализа.

Расписание работает через пользовательский LaunchAgent даже при закрытом MacSpace. Если компьютер выключен в назначенное время, помощник проверит просроченный запуск при следующем входе пользователя в систему. Включение или смена периодичности не запускает немедленную очистку. Ранее включённое расписание сохраняется при обновлении приложения.

Помощник установлен в ~/Library/Application Support/MacTidy/MacTidyHelper.app. Расписание: ~/Library/LaunchAgents/local.mactidy.weekly-downloads.plist. Результат: ~/Library/Application Support/MacTidy/weekly-report.json. При первом запуске после обновления MacSpace автоматически обновляет уже включённого помощника и сохраняет время следующей очистки. Выключение переключателя останавливает задание и удаляет plist. Перед удалением MacSpace отключите эту опцию.

Если macOS запрещает помощнику доступ к Загрузкам, файлы сохраняются и ошибка отражается в результате запуска. Результат обновляется при возвращении в MacSpace. Неудачные объекты не блокируют остальные; немедленных повторов нет.

## Сборка и проверка

`build.command` собирает приложение под архитектуру текущего Mac; для этого нужны Apple Command Line Tools со Swift и SDK macOS 26+. Пользователю готового установщика инструменты разработки и отдельная установка ClamAV не нужны. Сборка имеет локальную ad-hoc подпись, не нотарифицирована Apple для публичного распространения. Сине-серебристая иконка сделана как векторный SVG; PNG с прозрачным фоном и готовый ICNS находятся в Assets.

`test.command` запускает проверки обхода и исключений, отмены, устаревших метаданных, ссылок, типов файлов и установщиков, изменений вложенного кэша, фильтров дат, устранения повторов, защиты исключённых файлов, редко используемых приложений и расписания автоочистки. Реальный перенос в Корзину и восстановление проверяются только на специально созданном временном файле. Перенос пользовательских файлов и приложений при разработке не выполнялся.

Приложение работает локально и не отправляет найденные имена и содержимое файлов в сеть.

Для сборки самостоятельного установщика запустите `./package.command`: результат появится в `dist/` вместе с SHA-256. Исходники: [GitHub](https://github.com/RomanTheDev-cmd/MacTidy), лицензия MacSpace — [MIT](LICENSE). Встроенный ClamAV распространяется по GPL-2.0-or-later; соответствующий архив исходников создаётся в `dist/` для публикации вместе с установщиком. При обновлении основной программы включённый помощник обновляется автоматически.
