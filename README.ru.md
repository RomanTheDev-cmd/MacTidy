# MacTidy 2.1

Нативное приложение на SwiftUI для анализа места и переноса выбранных объектов в Корзину. Готовая сборка — Apple Silicon, macOS 13+. Интерфейс использует системный Liquid Glass на macOS 26 и новее (проверено на macOS 27), на более старых версиях — стандартные полупрозрачные материалы. Светлая/тёмная тема следует настройке системы. Графитовые кнопки имеют контрастные подписи.

## Установка

1. Скачайте **MacTidy-2.1.0-arm64.pkg** из [последнего релиза](https://github.com/RomanTheDev-cmd/MacTidy/releases/latest).
2. Откройте файл и пройдите обычные шаги установщика macOS.
3. Запустите MacTidy из папки «Программы».

Установщик самостоятельный, инструменты разработчика не нужны. Требуются Apple Silicon (M1 и новее) и macOS 13+. Перед обновлением закройте приложение. Установка не запускает очистку и не включает расписание; существующие настройки сохраняются.

Сборка имеет ad-hoc подпись, установщик не подписан сертификатом Developer ID и не нотарифицирован Apple. Если macOS блокирует скачанный файл, после попытки открытия найдите «Всё равно открыть» в «Системные настройки → Конфиденциальность и безопасность», если доверяете этой сборке. На управляемом Mac эта возможность может быть запрещена.

## Языки

Язык выбирается по первому предпочитаемому языку системы или приложения. В комплекте: русский, английский, немецкий, испанский, итальянский, вьетнамский, польский и индонезийский. Для остальных языков, поддерживаемых Apple Translation, на macOS 15+ используется системный переводчик с возможным запросом загрузки языковой модели. При отказе, ошибке или неподдерживаемом языке остаётся английский интерфейс. Изменение языка применяется после перезапуска. Дополнительные переводы машинные; исправления приветствуются.

Переводятся только фиксированные подписи интерфейса. Имена, пути и содержимое ваших файлов не передаются переводчику. Для арабского и иврита предусмотрено направление справа налево. Поддержка буквально всех языков не заявляется.

## Главное окно

Категории слева, результаты в центре, настройки и сведения справа; общий объём и действие «В Корзину» всегда видны. Галочки задают область анализа, название категории фильтрует готовый список. Поиск, сортировка по размеру/имени/дате, множественный выбор, переход в Finder и исключение объектов доступны в этом же окне.

Ничего не выбирается автоматически. Файлы, подходящие под несколько категорий, учитываются один раз. При наличии папки кэша её вложенные файлы не дублируются отдельными строками. Выбор сохраняется при смене фильтра, а скрытые выбранные объекты явно учитываются в нижней панели и подтверждении.

| Категория | Область и правило |
| --- | --- |
| Кэш приложений | Непосредственные объекты ~/Library/Caches с проверкой вложенного содержимого |
| Старые журналы | Обычные файлы ~/Library/Logs, изменённые более 30 дней назад |
| Установщики | DMG, PKG, MPKG, ISO, XIP в ~/Downloads и вложенных папках; только обычные файлы |
| Архивы | ZIP, RAR, 7Z, TAR, GZ, BZ2, XZ, TGZ, ZST в ~/Downloads |
| Старые загрузки | Обычные файлы, созданные, добавленные и изменённые более 30 дней назад; отсутствие даты создания не считается старостью |
| Сборки Xcode | Только ~/Library/Developer/Xcode/DerivedData; по умолчанию выключено |
| Большие файлы | Выбранная папка, порог 50/100/500 МБ или 1 ГБ |

Перед очисткой кэша закройте соответствующие приложения; перед очисткой DerivedData закройте Xcode. Следующий запуск или сборка могут занять больше времени. Кэш может содержать офлайн-данные для повторной загрузки. Возраст и размер файла не означают, что он больше не нужен.

Скрытые объекты, символические ссылки, пакеты приложений и вложенные Library, System, Applications, node_modules, .git не обходятся при рекурсивном поиске обычных файлов. Кэш измеряется отдельно, включая скрытое содержимое. Недоступные папки кэша не предлагаются для переноса; пропуски видны в отчёте. Отсутствующие необязательные папки могут давать пустую категорию.

Исключения сохраняются между запусками. Если исключённый файл находится внутри папки кэша, исключается вся эта папка, чтобы не переместить его косвенно. Кнопка «Вернуть исключённые» очищает список исключений; затем нужен новый анализ.

Размер обычных файлов — логический, папок кэша и приложений — сумма выделенных блоков. Облачные файлы, сжатие, общие блоки APFS и снимки влияют на фактическое освобождение места. Перед переносом повторно проверяются путь, идентичность, размер, даты изменения и состав вложенных папок. Эта проверка не является атомарной защитой от одновременного изменения файлов.

## Отдельное окно «Приложения»

Открывается кнопкой в верхней части главного окна. Проверяет /Applications и ~/Applications, включая вложенные папки, но не внутреннее содержимое приложений как отдельные приложения. /System/Applications, ссылки на приложения и сам MacTidy не предлагаются к удалению.

Фильтры: не открывались 30, 90 или 180 дней, либо все приложения. Дата последнего запуска берётся из Spotlight. Отсутствующая или неполная история не означает, что программа редко используется: такие приложения показываются только при включении «Показать без истории» или выборе всех приложений.

Запущенные приложения нельзя выбрать для удаления. Список запущенных обновляется по системным событиям и повторно проверяется перед переносом. Изменённое после анализа приложение не переносится до повторной проверки.

Переносится только пакет .app. Документы, настройки, Application Support и другие пользовательские данные не удаляются. Некоторые программы со службами, расширениями или драйверами требуют фирменного деинсталлятора. Приложения, защищённые macOS или правами доступа, могут не перенестись; ошибка будет показана. Программа не повышает права администратора.

## Еженедельная очистка Загрузок

Переключатель «Автоочистка загрузок» находится справа в главном окне. При первом включении требуется подтверждение: каждое воскресенье в 12:00 по времени Mac **всё содержимое ~/Downloads**, включая новые файлы, скрытые объекты и целые папки, переносится в Корзину. Символические ссылки переносятся как ссылки, их цели не обходятся. Корзина не очищается. Эта опция не зависит от галочек категорий ручного анализа.

Расписание работает через пользовательский LaunchAgent, после входа пользователя, даже при закрытом MacTidy. Пропущенный во время сна запуск может произойти при пробуждении. На выключенном Mac и до входа пользователя задача не работает. Включение не запускает немедленную очистку. Ранее включённое расписание сохраняется при обновлении приложения.

Помощник установлен в ~/Library/Application Support/MacTidy/MacTidyHelper.app. Расписание: ~/Library/LaunchAgents/local.mactidy.weekly-downloads.plist. Результат: ~/Library/Application Support/MacTidy/weekly-report.json. Выключение переключателя останавливает задание и удаляет plist. Перед удалением MacTidy отключите эту опцию.

Если macOS запрещает помощнику доступ к Загрузкам, файлы сохраняются и ошибка отражается в результате запуска. Результат обновляется при возвращении в MacTidy. Неудачные объекты не блокируют остальные; немедленных повторов нет.

## Сборка и проверка

`build.command` собирает приложение под архитектуру текущего Mac; нужны Apple Command Line Tools с SwiftUI и SDK macOS 26+ для сборки стеклянного интерфейса. Сборка имеет локальную ad-hoc подпись, не нотарифицирована Apple для публичного распространения. Иконка обновлена на чёрно-белую; PNG с прозрачным фоном и готовый ICNS находятся в Assets.

`test.command` запускает тесты на общих исходниках приложения. 57 проверок охватывают обход и исключения, отмену, устаревшие метаданные, ссылки, изменения вложенного кэша, фильтры дат, устранение повторов, защиту исключённых файлов, выбор редко используемых приложений, проверку запущенных и изменённых приложений и параметры недельного расписания. Реальный перенос в Корзину и восстановление проверяются только на специально созданном временном файле. Перенос пользовательских файлов и приложений при разработке не выполнялся.

Приложение работает локально и не отправляет найденные имена и содержимое файлов в сеть.

Для сборки самостоятельного установщика запустите `./package.command`: результат появится в `dist/` вместе с SHA-256. Исходники: [GitHub](https://github.com/RomanTheDev-cmd/MacTidy), лицензия [MIT](LICENSE). При обновлении основной программы включённый помощник сохраняется; чтобы обновить его, выключите и снова включите расписание.
